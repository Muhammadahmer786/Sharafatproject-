EXTERNAL INTELLIGENCE

Check a hash, URL, IP or file

{{ icon('globe') }}

Choose a tab in Threat intelligence. Look up an MD5, SHA-1 or SHA-256 hash, submit a public HTTP(S) URL, check public IPv4/IPv6 reputation, or upload any file type up to 20 MiB. IP checks retrieve reputation; they do not probe the address.

Review the disclosure before submitting: VirusTotal receives your indicator or complete uploaded file and may retain/share it. Use authorized, non-confidential data only. File bytes are not stored locally. The external workspace needs internet and an API key, but no Docker worker.

Queued checks continue in the background. Use Check history for results, engine findings, provider timestamps, refresh and JSON export. A missing report, failed engine or zero detections does not establish safety. Deleting a local record does not remove provider copies or previous backups.

SUPERVISED WORKFLOW

Adding OpenBin findings

{{ icon('spark') }}

Local OpenBin extracts code with Ghidra on this server. It does not run an AI model or create an automatic malware verdict.

  1. Create a scan using an authorized file. Local-only review needs no cloud consent; record consent before sending code to an external AI provider.
  2. Open Local OpenBin, upload the same sample and download its analysis JSON. Allow up to six minutes including worker startup.
  3. Review function addresses and decompiled code. If you separately use a model, check its findings against the actual evidence.
  4. Map the supported observations into Sentinel's JSON format below. Raw decompilation JSON cannot be imported directly as reviewed findings.
  5. Open the scan, choose “Import reviewed findings”, upload the JSON, and confirm evidence review.
{
  "schema_version": 1,
  "sha256": "EXACT_SHA256_FROM_YOUR_SCAN",
  "tool": "OpenBin",
  "processing_location": "local",
  "model": "Actual local model, or Manual review; no AI model",
  "reviewer": "Person who checked the code",
  "findings": [{
    "title": "Concise observation",
    "severity": "info",
    "detail": "Explain the observation and its limits.",
    "evidence": "Function/address/line and supporting code observation."
  }]
}

Allowed severity: info, low, medium, high. At most 50 findings. An empty list means the reviewer supplied no supported indicators; it does not mean the file is safe.
