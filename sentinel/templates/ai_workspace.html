ANALYSIS PROCESS

How the analysis works

  1. 01
    Extract static evidence

    OpenBin's Ghidra worker decompiles the binary in isolation, without executing the sample.

  2. 02
    Review with a local model

    The model examines a bounded selection of functions, imports and strings.

  3. 03
    Check every observation

    Findings include validated source quotations, coverage counts and limitations for your review.

Interpreting the result

This experimental workflow is not antivirus certification. A result with no indicators cannot establish that a file is safe. Model interpretations need human review.
