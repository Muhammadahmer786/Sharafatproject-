Processing & privacy

{{ icon('shield') }}

Working limits

  • External file upload: any extension, up to 20 MiB
  • Native x86/x64 PE files: up to 10 MiB
  • Documents: up to 5 MiB and available PNG capacity
  • PNG images: up to 22 MiB and 12 million pixels
  • Complete request: below {{ upload_limits.request // (1024 * 1024) }} MiB
  • RSA keys: 2048–4096 bits

What is retained

Account data, scan metadata, external check indicators/results, reviewed findings, consent, jobs, and basic activity events. Delete scans from their detail page.

The web app keeps uploaded files, documents and uploaded private-key files in memory only. Assigned public keys and encrypted private keys remain in the local account vault; the original server secret is required to unlock them. The separate OpenBin operator tool writes its decompiled output to the local path the operator selects.

Metadata backups remain in local operator storage after a scan is deleted. The operator controls backup retention.
