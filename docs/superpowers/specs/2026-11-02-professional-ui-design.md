# Professional workspace design

The user requested a professional redesign of the whole application and selected a light workspace with a charcoal sidebar, navy actions, compact tables and direct page titles.

Use the existing Flask/Jinja application and its routes. The design uses neutral surfaces, a readable system font, 14px body text, 28px page titles, 8px corner radii, subtle borders and semantic status colours. Remove decorative marketing heroes, orbit illustrations, excessive slogans and competing global themes. Preserve actual counts, disclosures, progress semantics, forms, CSRF, owner permissions and download behaviour.

Approaches considered: the selected light workspace provides clear forms and data; a dark analyst console was offered but not selected; retaining the existing purple palette would not address the requested overall change. Implementation details and spacing are the builder's choices within the selected direction.

The shared shell, dashboard, authentication, file and AI analysis, external intelligence, histories, protection/recovery, key views, account settings and admin screens must use the same design. Tables may scroll within their own container on mobile; the page must not overflow. Retain visible keyboard focus, responsive navigation and readable status labels. No fabricated charts or service health claims.

Verify desktop and mobile screens, keyboard controls, existing DOM contracts and route rendering. This is a presentation change; it does not alter the security model or create new analysis capabilities.
